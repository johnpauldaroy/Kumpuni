Printer help

What does Check and fix do?

Kumpuni reads the saved Windows queue, applies eligible repairs and checks the result. Windows may ask for administrator approval.

Does a ready result confirm a printed page?

Ready means Windows verified the queue. Print a document to confirm physical output.

Where are the guided checks and test pages?

Use Advanced tools for guided USB, network and shared printer help, manual repairs, and test pages.

What is in an exported report?

Exports include findings and Windows check results. Inventory exports replace identifying queue, driver and port names with report-local IDs.
